### 3.3 `extract_structured` schema 契約

| 項目 | 內容 |
|---|---|
| **OpenClaw 側觀察到的** | 契約**未寫在工具描述裡**這點 ✅ 一致（`tool_describe` 只回一句 "Structured extraction schema understood by camofox-browser"，`schema` 欄位只是 `type:object` 無結構定義）。**但實際形狀與 Hermes 描述不同**：<br>• Hermes 給的 `{"kind":"object","fields":{"link":{"kind":"url","selector":"a","attr":"href"}}}` **可用**，但 `matchedRoots:1`，只抽到全頁**第一個** `<a>`（HN 上拿到 `https://news.ycombinator.com/`，即頁首 logo 連結，不是新聞連結）。<br>• `kind:"list"` **搭配 `fields` 會直接失敗**：`schema.fields is not supported`。<br>• `kind:"list"` 正確寫法是 **`item`（單數物件）**，且需**頂層 `selector` 作為 root scope**：`{"kind":"list","selector":"tr.athing .titleline","item":{"kind":"url","selector":"a","attr":"href"}}` → 30 筆全數抽出（`matchedRoots:30`）。<br>• `item` 傳陣列會失敗：`schema.item must be an object`。<br>• `kind:"object"` + 頂層 `selector` 可限定 root，但回傳仍是**單一物件**（第一個 root），不是陣列。<br>• 欄位 `kind` 實測可用：`url`、`text`皆可；`selector` 相對於 root 解析。 |

| **建議寫進文件的正確 schema** | 單值：`{"kind":"object","fields":{名稱:{kind:"text\|html\|attr\|url\|number", selector:"相對root的選擇器", attr:"屬性名"}},"selector":"root選擇器(選填)"}`<br>陣列：`{"kind":"list","selector":"root選擇器","item":{kind:"url\|text\|html\|attr\|number", selector:"相對root的選擇器", attr:"屬性名"}}` |

   `get_links` 每次都「成功」但 92/92 筆 `href:""`，不報錯。這種**靜默錯誤比明確報錯更危險**（下游 AI會誤以為該頁沒有連結）。決策點：(a) 在 skill 裡明文標註 `get_links` 不可用、改走 `camofox_query_selector`（`attributes.href`）或 `extract_structured`(`kind:"url"`+`attr:"href"`)；(b) 向 camofox 上游回報；(c) 在 OpenClaw 端加一層「`get_links` 回空 href 時主動告警」的啟發式。

5. **【低】`get_stats` 強制要求 `tabId`，與「session statistics」描述不符。**
   工具描述是「Get session statistics: request counts, active tabs, uptime, performance metrics」，但 JSON Schema 把 `tabId` 列為 `required`，導致**開 tab 之前無法取得全域 stats**（本次第 2 項因此延後到建 tab 後才做，量到的是 per-tab 視角：`visitedUrls:["https://example.com/"], toolCalls:8`與 `remote.toolCalls:6`）。建議回報上游釐清，或確認 `tabId` 是否應為 optional。

6. **【低】`list_tabs` 描述宣稱回 titles，實際無 `title` 欄位。**
   與 `navigate` 的空 title 疑似同一條上游欄位路徑未實作。建議與第 3 點一併回報。

7. **【流程】本次沒有成功示範到一次 `close_tab`。**
   原始錯誤：`{"isError":true,"code":"TAB_NOT_FOUND","message":"Tab 'aa1febf6-3929-46c5-ac79-db8905f4aa94' is not tracked. Create or list tabs first."}`

## 6. 本次測試的侷限

1. **只有單一 client視角。** 所有結論來自 OpenClaw（Gateway pod內、MiniMax-M2.5/切 M3 pending）。Hermes 端結論是本次的對照組，我沒有從 Hermes 側重新執行任何一行，所以「兩邊一致」是**基於既有報告 + 我方獨立觀察比對**，不是雙向重現。

2. **screenshot 的圖片遺失根因尚未定案。** 我以 raw JSON-RPC 與官方 MCP SDK client 雙路確認 camofox 端有回合法 PNG，但 OpenClaw 內部的**確切丟失節點未經 runtime 插樁確認**——「模型無 vision 導致」是目前最強假說（`anthropic-messages.ts` `convertContentBlocks()` 的 `model.input.includes("image")` 閘門 + M2.5 為 text-only），但**尚未用 M3 實際驗證反證**。另外為了定位而動用了 `exec`（讀 openclaw.json 取 Bearer、跑 SDK client、比對 `/app/dist` 與 `@openclaw/ai` 原始碼），這些是**診斷性**手段、非 MCP 工具測試本身，所有功能判定仍以 MCP 工具回傳為準。
